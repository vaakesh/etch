# UI/UX-аудит Etch

Дата исходной проверки: 2026-08-04.

## Карта сайта

Источник истины — `src/app/router/route-config.ts`. `sitemap.xml` и дополнительные страницы в проекте отсутствуют.

| Путь                              | Доступ    | Проверенные состояния                                                                          |
| --------------------------------- | --------- | ---------------------------------------------------------------------------------------------- |
| `/login`                          | guest     | форма, обязательные поля, ошибка входа, уведомление об истёкшей сессии                         |
| `/`                               | protected | загрузка, данные, пустые колоды/активность, ошибка API                                         |
| `/library`                        | protected | колоды, карточки, поиск, избранное, пустые состояния, диалоги создания/редактирования/удаления |
| `/library/:deck_uuid/edit`        | protected | загрузка, данные, пустой состав колоды, ошибка/нет доступа/не найдено                          |
| `/practice`                       | protected | история, фильтры, пустая история, ошибка                                                       |
| `/practice?deck=:deck_uuid`       | protected | настройка новой сессии, валидация колоды                                                       |
| `/practice?session=:session_uuid` | protected | восстановление, процесс, результат и ошибки сессии (по коду и тестовым render-состояниям)      |
| `*`                               | public    | 404 и переход на главную                                                                       |

Отдельных маршрутов регистрации, политики конфиденциальности и иных второстепенных страниц в текущем frontend нет. Добавлять их без продукта и backend-контракта нельзя.

## Методика исходной проверки

- Firefox 152 headless, mock API только для воспроизводимых UI-состояний.
- Живой браузерный проход на 500 px (мобильный breakpoint; минимальная ширина управляемого окна Firefox), 768 px и 1440 px.
- Правила для 320–420 px дополнительно проверены по CSS media queries; точный WebDriver viewport 375 px заблокирован минимальной шириной Firefox.
- Проверены DOM-переполнения, доступные имена контролов, label/placeholder, ссылки, статические ресурсы, title/favicon, пустые состояния и визуальные скриншоты.
- Исходный baseline: `npm run typecheck`, `npm run lint`, `npm run test` — успешно, 218 тестов.

## Что исходно прошло без замечаний

- Внутренние рабочие ссылки ведут на зарегистрированные маршруты; ссылок `#` и внешних `<a>` нет.
- У полей есть программно связанные label; placeholder не заменяет label.
- `<img>` отсутствуют: декоративные SVG скрыты от accessibility tree, битых изображений нет.
- На проверенных страницах нет горизонтального скролла всего документа на 500/768/1440 px; найденные переполнения локальны и перечислены выше.
- Hover/focus/disabled-состояния определены в CSS для основных интерактивных компонентов.
- Google Fonts и frontend-модули загрузились без 404; чистый baseline не показал ошибок приложения в консоли.

## Повторная проверка

- 500 px: навигация помещается, touch-цели 44×44 px, фильтры практики не обрезаются.
- 768 px: навигация, история практики и 404 больше не выходят за viewport.
- 1440 px: desktop-раскладки главной, библиотеки, редактора и практики не изменились.
- Для всех маршрутов подтверждены корректные title, favicon и отсутствие горизонтального скролла документа.
- У видимых form-controls нет потерянных доступных имён; placeholder без label не найден.
