# Etch: колоды и карточки в библиотеке
<!-- chunk_id: etch.library.contents -->

В «Библиотеке» Etch вкладка «Колоды» показывает ваши собственные колоды и сохранённые колоды других пользователей. Во вкладке «Карточки» находятся ваши карточки.

Карточка может существовать без колоды или входить сразу в несколько ваших колод. Сохранение чужой публичной колоды не делает её карточки вашими и не даёт права их редактировать.

Нажмите название колоды, чтобы открыть её содержимое. Если список ещё не загружен полностью, используйте «Показать ещё». Пустая вкладка карточек не обязательно означает, что в сохранённых чужих колодах нет слов.

# Etch: поиск колод и карточек
<!-- chunk_id: etch.library.search -->

Для поиска колоды откройте «Библиотека» → «Колоды» и введите часть названия в поле «Поиск по колодам». Для поиска слова откройте вкладку «Карточки» и поле «Найти слово или перевод».

Поиск карточек работает по текстам обеих сторон. Поисковая строка ограничена 50 символами. В «Каталоге» отдельный поиск находит публичные колоды по названию.

Если результатов нет, сократите запрос, проверьте написание и очистите фильтр «Только любимые», если он включён. Для возвращения к полному списку очистите строку поиска.

# Etch: избранные колоды и вид библиотеки
<!-- chunk_id: etch.library.favourites -->

В библиотеке нажмите действие «Добавить в избранное» у нужной колоды. Фильтр «Только любимые» показывает только избранные колоды. Действие «Удалить из избранного» снимает отметку и не удаляет колоду.

Свою колоду можно сразу добавить в избранное. Чужую публичную колоду сначала нужно сохранить в библиотеку. Если убрать чужую колоду из сохранённых, её отметка избранного тоже снимается.

Переключатель «Вид колод» меняет отображение между полным и компактным. Он не изменяет карточки, доступ к колоде или результаты тренировок.
