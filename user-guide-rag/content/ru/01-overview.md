# Etch: для чего нужен сервис
<!-- chunk_id: etch.overview.purpose -->

Etch помогает учить слова с помощью карточек. Карточка содержит два текста и языки этих текстов, например «привет» и «hello». Колода объединяет карточки по теме.

В Etch можно создавать свои колоды, публиковать их, сохранять публичные колоды других пользователей и тренироваться, вводя ответы с клавиатуры. Сервис хранит тренировочные сессии, историю ответов и показатели занятий.

Для библиотеки, каталога, практики и профилей требуется вход в аккаунт. Публичность колоды означает доступность другим вошедшим пользователям.

# Etch: как начать первую тренировку со своей колодой
<!-- chunk_id: etch.overview.first-practice -->

1. Зарегистрируйтесь или войдите в Etch.
2. Откройте «Библиотека» → «Колоды» и нажмите «Новая колода».
3. Введите название и создайте колоду.
4. Во вкладке «Карточки» создайте карточку, затем через её меню «Добавить в колоду» выберите созданную колоду. Вместо ручного ввода можно использовать «Импорт» JSON.
5. У колоды нажмите «Начать тренировку».
6. В настройке сессии выберите направление и количество карточек, затем запустите тренировку.

Для тренировки нужна хотя бы одна карточка. Если своих материалов нет, подходящую публичную колоду можно найти в «Каталоге».

# Etch: где находятся основные разделы
<!-- chunk_id: etch.overview.navigation -->

В боковом меню Etch доступны «Главная», «Библиотека», «Каталог», «Практика» и «Настройки».

- «Главная» (`/`) показывает колоды и показатели занятий.
- «Библиотека» содержит вкладки «Колоды» (`/library/decks`) и «Карточки» (`/library/cards`).
- «Каталог» (`/catalog`) содержит публичные колоды.
- «Практика» (`/practice`) показывает тренировочные сессии.
- «Настройки» (`/settings`) позволяют менять язык и оформление.

Свой профиль можно открыть по имени пользователя в боковом меню. Пункт «Статистика» пока не подключён; показатели занятий смотрите на главной странице.
