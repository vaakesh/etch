# Etch: импорт карточек из JSON
<!-- chunk_id: etch.import.steps -->

В библиотеке нажмите «Импорт». Выберите свою колоду, перейдите к вводу JSON, вставьте текст или нажмите «Открыть .json». После проверки нажмите «Импортировать» и дождитесь сообщения об успехе.

Новые карточки добавляются в конец выбранной колоды. За один импорт принимается от 1 до 500 карточек. Вместе с уже имеющимися карточками в колоде не должно быть больше 5000.

Если нужной колоды нет в списке импорта, закройте окно, создайте или загрузите свою колоду в библиотеке и откройте импорт заново. Чужая сохранённая колода не подходит для импорта ваших карточек.

# Etch: пример JSON для импорта карточек
<!-- chunk_id: etch.import.format -->

Импорт Etch принимает объект с обязательным массивом `cards`. В каждой карточке нужны `front_text` и `back_text`. Пример:

```json
{
  "cards": [
    {
      "front_text": "привет",
      "back_text": "hello",
      "front_lang": "ru",
      "back_lang": "en"
    },
    {
      "front_text": "спасибо",
      "back_text": "thank you",
      "front_lang": "ru",
      "back_lang": "en"
    }
  ]
}
```

`front_text` и `back_text` — две стороны карточки. В форме ручного редактирования `back_text` соответствует «Иностранное слово», а `front_text` — «Перевод». Языки необязательны: по умолчанию `front_lang` равен `ru`, а `back_lang` — `en`. Для другой пары языков укажите коды явно.

В поле импорта вставляется сам JSON без Markdown-ограждений с тройными обратными кавычками.

# Etch: ошибки импорта JSON и ограничения
<!-- chunk_id: etch.import.errors -->

При ошибке импорта Etch проверьте:

- В корне находится объект с массивом `cards`, а не массив сам по себе.
- В массиве от 1 до 500 объектов карточек.
- `front_text` и `back_text` — непустые строки длиной до 255 символов после удаления пробелов по краям.
- Коды языков, если указаны, содержат 2–3 латинские буквы.
- Использованы двойные кавычки, нет лишней запятой после последнего элемента и закрыты все скобки.
- В колоде достаточно места в пределах 5000 карточек.

Путь `cards[0].front_text` в сообщении указывает на первую карточку, `cards[1]` — на вторую. Если файл не читается, попробуйте вставить его JSON вручную.
