# Etch: a deck or profile cannot be found
<!-- chunk_id: etch.help.not-found -->

If Etch says a deck was not found or is unavailable, check the link and the account you are signed in to. A private deck is visible to its owner. The author may have deleted the deck or changed access.

If you previously saved the deck or practiced with it, check “Library” → “Deck archive”. An available archive entry can be restored as a personal copy before it expires.

For profile errors, check the username in `/users/username`. An unknown page address may lead to a 404 page; open the section through the navigation menu.

# Etch: network or server errors while saving
<!-- chunk_id: etch.help.network -->

If Etch cannot reach the server, check your connection and retry loading. If the server is temporarily unavailable, try later. Sign in again if your session has expired.

If an error occurs after creating a deck, importing cards, or saving another change, check the result in your library first. The response may have been lost after the operation completed. Immediately repeating creation or import can add unwanted duplicates.

When asking for help, describe the section, action, and error message. You do not need to provide your password or authentication data.

# Etch: cannot start or continue practice
<!-- chunk_id: etch.help.practice -->

For a new session, check that the deck is available and contains cards, and that the requested size is a whole number from 1 to 500. If the practice link is invalid, select the deck again from the library or catalog.

A completed session cannot accept answers or be continued; start a repeat session. “This card has already been answered” means the service will not replace a previously accepted answer.

If the deck was archived, check whether restoration is available. Continuing may be unavailable if the deck was deleted or its archive expired. For a network error, retry loading after reconnecting.

# Etch: features missing from the current interface
<!-- chunk_id: etch.help.unsupported -->

The current Etch web interface has no forgotten-password reset form, controls for changing your password, email, or username, or a delete-account button. Do not describe nonexistent “Settings” buttons for these actions.

Card import in the interface supports JSON. CSV, Excel, and Anki uploads and a separate card export button are not implemented. The “Statistics” section is not connected yet; available metrics are on the home page.

Automatic translation, word pronunciation, and semantic synonym checking are not presented as features of the current interface. These limitations apply to the project version checked on October 12, 2026.
